# 单位与温度表达式 · 精确有理数推导

为什么有这个项目：把摄氏温度当作可以随便乘的普通数，`20°C×2`、
`20°C + 300K` 这类表达式会算出貌似合理却没有物理意义的结果。
本服务把**绝对温度**（K / °C / °F）与**温差**（dK / dC / dF）分成两种
数量种类，所有数值用**约分有理数**（`math/big.Rat`）计算，所有量都带
**长度 / 质量 / 时间 / 温度的维度向量**，所有运算用约分有理数与维度向量完成。
非法运算在求值阶段被拒绝并定位到最小表达式区间。

- `units/`：Go HTTP 服务（词法 → 语法树 → 有理数量纲求值）
- `desk/`：Vue 3 + Vite 页面，编辑表达式、高亮错误区间、展示逐步推导
- `docker-compose.yml`：分别启动 `units`（:8080）与 `desk`（:5173）

## 表达式语言

- 有理数字面量：整数 `3`、小数 `1.5`、分数 `3/4`（分数两侧无空格；
  `1 / 2` 带空格是除法）
- 括号 `( )`、加减乘除 `+ - * /`（也接受 `× ÷ −` 等全角符号）
- 单位：
  - 长度 `m` `cm`；质量 `kg` `g`；时间 `s` `min`
  - 绝对温度 `K` `°C`（也可写 `C`）`°F`（也可写 `F`）
  - 温差 `dK` `dC` `dF`
- 无单位字面量是无量纲普通数，可作系数，如 `2 min * 3`

## 温标换算（精确有理数）

- `K = C + 27315/100`
- `K = (F − 32) × 5/9 + 27315/100`
- 华氏温差按 `5/9` 折算为开尔文温差；`dC` 与 `dK` 等大

所有内部值先换算到基准单位 `m, kg, s, K`，结果再换算到目标单位。

## 运算规则（种类 × 维度）

| 运算 | 规则 |
| --- | --- |
| `绝对 * /` | 一律非法（绝对温度不是可乘的普通数） |
| `绝对 + 绝对` | 非法 |
| `绝对 − 绝对` | 温差 |
| `绝对 ± 温差`、`温差 + 绝对` | 绝对温度 |
| `温差 − 绝对` | 非法 |
| 其余加减 | 维度必须相同；温差与同维量相容 |
| 乘除 | 维度向量相加/相减；除数不能为零 |

## 区间输入

页面有“区间推导”模式（表达式出现 `[数字` 时会自动进入）；HTTP
`POST /api/eval-range` 接受与 `/api/eval` 相同的请求体。区间字面量写为
`[下界,上界] 单位`，例如 `[20,21] °C - [68,86] °F`。端点可以为负数；
标量字面量视为退化为单点的区间。

区间运算在基准单位上按闭区间传播，结果覆盖输入区间内的**所有**取值：
加/减交叉端点组合，乘/除枚举四个端点组合取最值，一元负号交换上下界。
摄氏/华氏换算只是带正系数的仿射平移，端点次序不变，因此
`[20,21] °C - [68,86] °F = [-10,1] dK`（换算到 dF 为 `[-18, 9/5]`）。
除数区间包含零（跨零或退化为 `[0,0]`）时，商在零附近无界，服务返回 400
`DIVISION_BY_ZERO_RANGE` 并把错误定位到该除法子表达式。

区间响应的 `root` 给出目标单位下的 `lower/upper` 与基准单位下的
`lowerBase/upperBase`，`steps` 中每个节点都带 `lowerBase/upperBase`；
种类、维度、目标单位校验与错误定位规则与标量接口完全一致。
含区间字面量的表达式不能走标量接口（`RANGE_REQUIRES_RANGE_EVAL`）。

## API

```bash
curl -s -X POST http://localhost:8080/api/eval \
  -H 'Content-Type: application/json' \
  -d '{"expression":"100 °C - 20 °C","target":"dF"}'
```

成功返回每个语法节点（字面量 / 一元 / 括号 / 二元）的类型、种类、
维度向量、基准精确值与推导说明，以及根节点在目标单位下的精确分数与小数。
失败返回 400：

```json
{"error":{"code":"ABSOLUTE_TEMPERATURE_MULTIPLY",
  "message":"绝对温度不能相乘或相除……","pos":0,"end":8}}
```

`pos/end` 是 rune 偏移闭区间，指向出错的**最小**子表达式。
`target` 可省略（自动选择基准导出单位）。

## 本地运行

```bash
# Go 服务
cd units && go run ./cmd/units            # :8080

# 前端（另一个终端，自动代理 /api 到 :8080）
cd desk && npm install && npm run dev      # :5173
```

## Docker Compose

```bash
docker compose up --build
# 页面 http://localhost:5173 ，API http://localhost:8080
```
